Política de Privacidade

Última atualização: 23 de outubro de 2026

Esta política explica quais dados o Gestor Jurídico (“o programa”) trata, como e por quê, em conformidade com a Lei Geral de Proteção de Dados (Lei nº 13.709/2018 — LGPD).

1. Onde os dados ficam

O Gestor Jurídico roda no computador do escritório. Os dados cadastrados (usuários, clientes, pastas, processos, compromissos, prazos, publicações e arquivos) são gravados em um banco de dados local, nesse computador ou no servidor que o próprio escritório escolher. Não mantemos cópia desses dados em servidores nossos.

2. Dados tratados

  • Cadastro de usuários: nome, e-mail, número de inscrição na OAB e UF, e senha (guardada apenas em forma criptografada).
  • Dados do escritório: clientes, partes, processos, documentos e compromissos que os próprios usuários cadastram.
  • Publicações: o programa consulta a API pública do DJEN (Conselho Nacional de Justiça) pelo número da OAB do usuário para trazer as intimações publicadas.
  • Chave de IA (opcional): se o escritório cadastrar uma chave própria da Anthropic, o texto das peças enviadas para análise é transmitido à API da Anthropic somente quando o usuário pede a análise.

3. Dados de usuário do Google

A integração com o Google Agenda é opcional e só é ativada quando o usuário clica em “Conectar Google Agenda” e autoriza o acesso na tela do Google.

Permissões solicitadas:

  • openid e email — para identificar qual conta Google foi conectada e exibir esse e-mail ao usuário;
  • https://www.googleapis.com/auth/calendar.events — para criar, atualizar e excluir no Google Agenda do usuário os eventos correspondentes aos compromissos, audiências e prazos cadastrados no programa.

Como usamos: quando o usuário cadastra, altera, remarca ou exclui um compromisso no Gestor Jurídico, o programa faz a mesma alteração no evento correspondente do calendário principal do usuário. O programa só manipula os eventos que ele mesmo criou; ele não lê, lista, altera ou exclui outros eventos da agenda do usuário.

O que guardamos: no banco de dados local do escritório ficam guardados apenas o e-mail da conta Google conectada, o token de atualização (refresh token) concedido pelo Google e o identificador de cada evento criado pelo programa. Nenhum desses dados é enviado para servidores nossos ou de terceiros.

Compartilhamento: os dados de usuário do Google não são vendidos, compartilhados, transferidos a terceiros, usados para publicidade nem usados para treinar modelos de inteligência artificial.

Revogação e exclusão: o usuário pode desconectar o Google a qualquer momento em Minha Conta, no próprio programa, o que remove do Google Agenda os eventos criados pelo programa e apaga o token e o e-mail do banco de dados local. O acesso também pode ser revogado em myaccount.google.com/permissions.

O uso e a transferência, para qualquer outro aplicativo, de informações recebidas das APIs do Google seguirão a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

4. Segurança

A comunicação com o Google, o DJEN e a Anthropic é feita por conexões criptografadas (HTTPS). O acesso ao programa exige login e senha de cada usuário. A segurança do computador ou servidor onde o banco de dados fica é responsabilidade do escritório.

5. Retenção

Os dados ficam no banco local enquanto o escritório mantiver o programa e os registros. O escritório pode apagar registros pelo programa ou excluir a pasta de dados a qualquer momento.

6. Direitos do titular

Pela LGPD, o titular pode pedir confirmação, acesso, correção, anonimização, portabilidade e eliminação dos seus dados. Como os dados ficam sob controle do escritório que usa o programa, o pedido deve ser feito ao escritório; podemos ajudar pelo contato abaixo.
